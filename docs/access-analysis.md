# アクセス解析について

本サイトでは、利用状況の把握および改善のため、Google Analytics 4（GA4）を利用しています。

本サイトでは分析用Cookieを保存しない設定でGA4を使用しています。
また、Google Signalsおよび広告パーソナライズ機能は無効としています。
このため、Cookie同意ダイアログは表示していません。

ただし、アクセス時にはIPアドレス、ブラウザや端末に関する情報、閲覧ページ等の情報がGoogleに送信される場合があります。

Googleによるデータの取り扱いについては、Googleのプライバシーポリシー等をご確認ください。
