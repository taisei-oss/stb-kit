# CLI upgrade

`upgrade`は、ST-BridgeファイルをSTB-KITが対応する最新版へ更新します。

## 代表例

### ファイルを最新版へ更新する

```bash
stbkit upgrade input.stb -o upgraded.stb
```


## 主なオプション

- `-o`, `--output`: 出力ファイルのパス。`-`で標準出力を使用します。
- `-y`, `--yes`: 既存の出力先を確認なしで上書きします。
- `--input-encoding`: 入力ファイルのエンコーディングを指定します。

## 終了コード

- 0:変換が完了し、errorが記録されなかった場合
- 1:変換は完了したが、変換中にerrorが記録された場合
- 2:引数や指定が不正で変換を開始できない場合
- 3:読み込みや変換に失敗し、変換を完了できなかった場合
- 4:任意依存パッケージが不足し、要求された変換を実行できない場合


## 注意事項

- バージョンダウンはサポートしていません。
- 出力先が既に存在する場合は、上書き確認が表示されます。自動実行では`-y`の指定が必要です。
