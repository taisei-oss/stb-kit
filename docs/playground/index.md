# お試しアプリ

ブラウザ上でSTB-KITの機能を試すことができます。

[ST-Bridge -> IFC 変換お試しページ](converter/to_ifc.html){ .md-button .md-button--primary }

データの取り扱いについて

- 起動時にPython実行環境、利用ライブラリ等をインターネットから取得します
- ST-Bridgeファイルや変換後の内容は外部サーバーへ送信されません。ファイルはブラウザ内のみで取り扱います。
  変換ページで「初期化が完了しました」と表示された後は、そのページを閉じない限り、インターネット接続を切断して変換できます。
- 機密情報を含むファイルを扱う場合は、利用する組織の情報管理ルールを確認してください。
